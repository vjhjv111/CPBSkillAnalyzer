스킬 변경 판독기

스킬 변경 화면을 캡처해서 올리면 기존 스킬과 변경 후보의 실제 가치를 데이터시트 기준으로 계산해서 비교해드려요.

1기준 설정

선수 종류
카드 종류

카드 종류·포지션에 맞는 전용 스킬은 아래 "스킬 추가" 목록 상단에 먼저 뜨도록 정리돼요. 스킬 레벨(등급)은 카드마다, 스킬마다 각 줄에서 따로 고를 수 있어요 — 레벨 1~4로 표시된 스킬은 데이터시트에 값이 없어 5로 계산돼요.

2스크린샷 업로드 (선택 — 없어도 3번에서 수동으로 추가 가능)

Anthropic API 키 — 이미지 인식에만 사용

console.anthropic.com에서 발급받은 키예요. 이 브라우저에만 저장되고 Anthropic API로 직접 전송돼요 — 공용 컴퓨터나 다른 사람과 공유하는 화면에서는 입력하지 마세요. 키가 없어도 3번에서 스킬을 직접 골라 계산할 수 있어요.

✓ 이 배포본은 서버 프록시를 통해 이미지 인식을 처리해요. API 키를 입력할 필요 없어요.

4라인업 스코어보드 — 선수별 스킬 점수 한눈에 보기

    
게임의 '한눈에 보기' 화면처럼 여러 선수가 한 번에 나온 스크린샷을 올리면, 선수별로 장착된 스킬 점수 합계를 계산해서 순위를 매겨줘요. 이름에 '연도가 붙어 있으면(예: 로사리오'17) 골든글러브/시그니처 카드로, 연도가 없으면(예: 정근우) 임팩트 카드로 기본 추정해요 — 필요하면 각 선수 줄에서 직접 바꿀 수 있어요.
