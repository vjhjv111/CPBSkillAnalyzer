# 스킬 변경 판독기

## 실행

Node.js 18 이상에서 `npm ci` 후 `ANTHROPIC_API_KEY` 환경변수를 설정하고 `npm start`를 실행합니다. Render에서는 기존 Start Command `npm start`를 유지합니다.

## 스크린샷 분석

- 스킬 변경과 라인업 모두 Sonnet/Haiku 선택값을 서버가 실제 호출에 반영합니다. 기본값은 Sonnet입니다.
- 분석하기를 누르면 영역 확인 창이 열립니다. 스킬 변경은 기존/변경 영역을 각각 선택한 뒤 드래그해 조정합니다.
- 라인업은 머리글을 제외한 표 본문(이름·포지션·스킬 포함)을 선택하고 선수 행 수를 입력합니다. 균등 분할선이 선수 사이에 맞아야 합니다. 행 높이가 다른 화면은 나누어 업로드하세요. 한 장당 최대 18행입니다.
- 원본의 축소 이미지는 배치 확인용으로, 잘라낸 PNG는 글씨 판독용으로 함께 전송합니다. 상세 이미지는 최대 2배 확대하되 긴 변 1500px, 약 105만 픽셀 이내로 제한합니다. 원본에 없는 글자 정보를 복원하지는 않습니다.
- 이름 오타와 여러 계산 조건이 있는 스킬은 자동 확정하지 않습니다. 후보가 선택 목록 위에 표시되며 사용자가 확정합니다.
- 읽지 못한 레벨은 `미인식`으로 남습니다. 실제 1~4레벨은 그대로 표시하고 점수 계산에만 5레벨 값을 사용합니다.
- 미확정 항목이 있으면 부분 합계를 표시하며 스킬 변경 추천과 해당 선수의 순위를 보류합니다.

## 검증과 수정

`npm test`는 레벨 검증, 이름 후보 매칭, 행 분할, 모의 Anthropic 응답을 사용하는 서버 요청 테스트를 실행합니다. 실제 API 키나 유료 호출이 필요하지 않습니다.

실제 게임 화면의 인식률은 별도 확인이 필요합니다. 영역 분할로 이미지 수와 입력 토큰이 증가하며, Sonnet은 Haiku와 요금이 다릅니다.

서빙 원본은 `public/index.html`입니다. 수정 후 `npm run build:standalone`으로 독립 실행 파일 `skill_analyzer.html`을 갱신합니다. 독립 파일은 기존처럼 사용자가 입력한 API 키로 직접 호출합니다.
